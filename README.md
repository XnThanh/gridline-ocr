## Setup

`pip install numpy`

`pip install opencv-python`

`pip install matplotlib`

## Running the Code

1. place image into `input` folder
2. run `python main.py`
3. follow prompts

## Notes

### generate.py (for testing)

This file is for generating images with random black and white pixels, with option to add horizontal and vertical gridlines (i.e. white lines). To run file, run `python .\tests\generate.py` and follow prompts.

### edge cases

- non-white background
- empty cells, for example, in set F images, some entries for traditional chinese characters are empty (since they are the same character as simplified)
- mixed language cells (ex: E1, some english translations may include chinese characters)
- text styles such as underlining (ex: I1)
